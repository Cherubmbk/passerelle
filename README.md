# Passerelle Emploi

Prototype d'application d'aide à la recherche d'emploi, en français.

- `index.html` : toute l'application (HTML, CSS et JavaScript dans un seul fichier).
- `data/feed.json` : copie de la rubrique « Info pratique » (événements, actualités, bons plans) au 6 novembre 2026.

## Voir le site

Ouvrez `index.html` dans un navigateur, ou activez GitHub Pages (Settings → Pages → branche `main`, dossier `/root`).

## Limites hors de claude.ai

La version publiée sur claude.ai utilise des fonctions propres à Claude (conseillère, mise à jour automatique de « Info pratique »).
Hébergée ailleurs, la page passe en « Mode simplifié » : ces fonctions sont désactivées et la rubrique « Info pratique » affiche les données intégrées à la page.
